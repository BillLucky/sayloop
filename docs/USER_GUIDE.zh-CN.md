# Sayloop 使用说明

## 打开与生成

在项目目录双击 `start.command`，或运行 `.venv/bin/python scripts/serve.py`，打开 `http://127.0.0.1:8765`。程序完全在本机处理文本；首次安装所需的模型和词典准备好后即可离线使用。

在 **My materials** 选择文章，或点击 **New material** 粘贴文本。**Import .txt / .md** 支持 UTF-8 文本和 Markdown。生成前会自动保存当前版本；修改原文后再次生成会创建新版本，不覆盖之前的文章。

在 **Speech studio** 选择语言与音色、语速、段落间隔。语言选项是朗读语言，不会替你翻译原文。先点 **Preview first 25 seconds**；满意后点 **Generate full audio**。短文本的试听会短于 25 秒。

**Voice collection** 中有九个美式男声的对比入口。默认长文使用 Fenrir，也可以试 Michael 和 Puck；声音偏好由你试听决定，没有人为虚构的情绪强度控制。

## 三种练习方式

在文章卡片点击书本图标，进入 **Practice room**：

- **Continuous**：连续播放，当前句高亮；打开 **Auto-follow** 后，下一句超出视野时自动滚动。
- **Listen & speak**：听完一句自动暂停，保留当前句让你跟读。读完按空格，放行下一句。
- **Loop sentence**：循环当前句。按右方向键切到下一句，继续循环。

| 按键 | 动作 |
| --- | --- |
| 空格 | 暂停 / 原位置继续；跟读等待时进入下一句 |
| R | 当前句从头再听一遍 |
| ← / → | 上一句 / 下一句 |
| F | 进入 / 退出沉浸模式 |
| Esc | 退出沉浸模式 |

鼠标点过某一句后，空格仍然是暂停/继续，不再触发该句的重复点击。输入框、下拉框以及输入法组词期间不会抢占快捷键。

点击 **Immersive** 进入大字听读界面：当前句突出显示，上下文弱化，句末轮到你读时显示 **YOUR TURN TO SPEAK**。窗口顶部的退出按钮或 Esc 都能返回。普通页面左上角可折叠侧栏。侧栏状态、跟随选项和练习模式会在当前浏览器中记住。

**Hide text** 可隐藏文字练背诵；播放条可以拖动、变速、整篇循环和下载。屏幕显示的每日时长是播放时间，不代表真正开口练习的时长。

## 文件与备份

网页支持 MP3、WAV 下载，以及整批 ZIP。运行 `.venv/bin/python scripts/export_library.py` 可生成有名称的本地音频包。原文、生成记录、音频都在本地 `data/`，不会进入 GitHub 仓库。

需要迁移时，保存浏览器里的草稿到文章库，停止空闲服务，备份整个 `data/`。不要只复制 MP3，因为逐句时间点在 `data/jobs/`。详细部署与恢复方式见 [运维说明](OPERATIONS.md)。

## 手机和散步练习

推荐在手机上安装并连接 Tailscale，始终使用电脑配置好的同一个 HTTPS 地址。在 Practice room 中选择录音，点 **Save on this device**，出现已保存提示后再重新打开录音；后续播放和跳句使用手机缓存。每篇分别保存，**Remove device copy** 只清除浏览器保存副本。不同浏览器、局域网 IP 和 HTTPS 地址的缓存互不相通。网页和字幕仍要连接电脑，电脑需保持开机清醒；纯离线使用可下载 MP3 到手机播放器。配置步骤见 [REMOTE_ACCESS.md](REMOTE_ACCESS.md)。
