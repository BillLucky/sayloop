# Sayloop 使用说明

## 登录与数据边界

**语音在本机生成，创作使用你配置的语言模型。** 模型和词典准备好后可以离线合成语音；润色、翻译与场景创作是否联网，取决于模型配置。提交前请确认模型服务的管理者和访问范围。

**首次启动会在私有目录生成 owner 账号。** 初次用 `data/OWNER_LOGIN.txt` 中的密码登录，再到“学习进度”修改密码。修改后使用自己设置的密码；初始文件不会自动更新。管理员可生成一次性邀请码供其他学习者注册。

本机运行 `.venv/bin/python scripts/serve.py`，打开 `http://127.0.0.1:8765`；macOS 也可双击 `start.command`。局域网和私有远程入口需单独配置，见[远程访问](REMOTE_ACCESS.md)。

## 从想法到学习材料

1. **润色中文：** 打开“创作”，写下想说的话，点击“润色中文”。场合与修改要求收在“更多设置”中，按需补充。
2. **生成外语表达：** 直接修改“中文定稿”，满意后点击“生成外语表达”。想先选语言或风格，在“其他操作”中点“调整语言和风格”；数量、人称在“更多设置”中。
3. **继续打磨：** 点击结果上方“继续打磨”，会打开修改要求并保留当前结果。输入“更简短”“更礼貌”等要求后，再提交一版。
4. **场景对话：** 选择“场景对话”，写明双方身份、情境和目标。默认生成三组，每组六轮；数量和轮数可在“更多设置”调整。模拟情节中的日期、金额与经历须自行核对。
5. **编辑与保存：** 对话按组折叠，点标题展开后可以逐轮修改台词、释义和角色。点击“保存并配音”，语料默认私有，随后选择声音。

**等待状态不必重复点击。** 网络提交和读取历史时，编辑区会短暂只读，完成后恢复。相同内容因断线重试不会重复创建已受理任务。 提交后会保留服务器版本，页面显示生成状态。遇到错误可以保留原文重试；离开页面后，已提交任务仍在服务器继续。旧版本在“历史版本”中。

**草稿状态反映当前浏览器的保存结果。** 换浏览器、换网址不会自动带走未提交草稿。浏览器存储不可用时仍可生成，但请复制重要内容或提交保存。已有对话的未保存修改也会在同一浏览器恢复。退出账号会清理该账号的本地草稿和设备音频，不删除服务器原件。

## 声音与配音

**先试听，再生成完整录音。** 在语音工作台选择正文对应的语言和声音。语言选项控制朗读，不会替你翻译。语速、段落停顿按需展开；短文本的试听可能不足25秒。

**对话角色可分别选择男声或女声。** 保存对话后，为 A、B 各选声音。角色名与中文释义保留在练习界面，不会念入录音。声音库支持语言和性别筛选；文本风格不保证某个声音具有对应地域口音。

## 手机与语料管理

**手机底部只有“语料 / 创作 / 练习”。** 右上角“更多功能”可打开配音、声音库、学习进度和账号操作。点关闭、弹层外部或 Esc 可以收起菜单。

**高频操作直接点，低频操作按需展开。** 语料卡片提供练习或配音；卡片“…”中管理标签、收藏、归档和共享。“筛选与排序”可区分语言、对话/独白、自己的/共享语料及归档状态。

共享会开放材料及原主人相关录音给所有已登录用户。撤销共享可阻止之后的服务器访问，但无法收回别人已经下载或保存的副本。

## 练习与设备音频

| 方式 | 行为 |
| --- | --- |
| 连续听 | 连续播放，当前句高亮 |
| 逐句跟读 | 句末暂停，轮到你说；读完后按空格继续 |
| 单句循环 | 重复当前句，可切到下一句 |
| 专注练习 | 大字显示当前句，退出后回到普通页面 |

| 按键 | 动作 |
| --- | --- |
| 空格 | 暂停/继续，或在跟读等待后前进 |
| R | 重播当前句 |
| ← / → | 上一句/下一句 |
| F / Esc | 进入/退出专注 |

输入框、下拉框和输入法组词期间不会抢占快捷键。鼠标点句子可定位；“自动跟随”使当前句保持可见。学习进度统计有效播放时间，不代表真实开口时长或发音评分；排行榜需主动加入。

**设备音频可以重复使用。** 在“练习 → 离线音频与反馈”保存录音，刷新后播放和定位使用同一浏览器的设备副本。网址、浏览器和账号要保持一致；网页和字幕仍需连接服务器。下载MP3到其他播放器可用于纯离线听读。

## 文件与备份

**个人资料不随源码公开。** 原文、录音、账号、本机配置、截图和备份保存在忽略的 `data/`。运行 `scripts/export_library.py` 生成的音频包也是私人文件，不是公开源码交付物。

迁移前先把重要草稿保存入库，等待生成队列空闲后停服务，再备份整个 `data/`。不要只复制MP3，账号归属和逐句时间点也需要保留。详见[运维说明](OPERATIONS.md)及[语料创作设计](LEARNING_WORKSPACE.md)。
