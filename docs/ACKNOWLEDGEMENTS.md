# Acknowledgements

## Learning inspiration

Thank you to **Li Xiaolai** ([xiaolai](https://github.com/xiaolai)) for sharing [1000 Hours / 一千小时](https://1000h.org/why.html), and to the maintainers and contributors of [everyone-can-use-english / 人人都能用英语](https://github.com/ZuodaoTech/everyone-can-use-english), including Enjoy.

The [kick-off task](https://1000h.org/training-tasks/kick-off.html) inspired Sayloop's small, concrete workflow: prepare personally meaningful text, generate a listening reference, then listen, speak, and repeat. This is our application of part of that learning approach, not a claim to implement the whole curriculum or guarantee a learning outcome.

The [1000-hours source directory](https://github.com/ZuodaoTech/everyone-can-use-english/tree/main/1000-hours) contains the website material; its [introduction](https://github.com/ZuodaoTech/everyone-can-use-english/blob/main/1000-hours/intro.md) credits Li Xiaolai. The older [xiaolai/1000-hours](https://github.com/xiaolai/1000-hours) README redirects readers to the successor repository.

Sayloop is independently developed. No affiliation, approval, or endorsement by the author, Enjoy, or ZuodaoTech is implied. Their articles and application code are not bundled or relicensed as Sayloop source.
